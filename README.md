# Бот подписки «Экономизм Private»

Бот принимает оплату подписки на закрытый канал через интернет-эквайринг Т-Банка, сам открывает и закрывает доступ и ведёт реестр для ДДС и управленческого PnL.

Подписка на сайте через CloudPayments не меняется. Это второй вход: человек платит там, где удобнее.

## Что умеет

- Четыре тарифа: 3 990 ₽ / 10 990 ₽ / 19 990 ₽ / 37 990 ₽. Цену бот подставляет в каждый платёж сам.
- Почта для чека. Телефон не спрашивает.
- Предупреждение за 48 часов до списания и кнопка отмены автопродления.
- Повтор списания через 12 часов, если банк отказал. Ещё через 12 часов человек выходит из канала и не остаётся в чёрном списке.
- Акции с датой окончания и одноразовые промокоды. Цена, по которой человек оплатил, сохраняется на продления.
- Реестр `data/ledger.csv`: ник, почта, срок, сумма, начало и конец периода. Команда `/export` присылает файл.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env
.venv/bin/python -m unittest discover -s tests
.venv/bin/python -m app
```

Пока в `.env` нет `BOT_TOKEN`, поднимается только служебный адрес `http://127.0.0.1:8741/health`.

Проверки:

```bash
.venv/bin/python -m unittest discover -s tests
```

## Что заполнить в .env

Смотрите `.env.example`. `TAXATION=usn_income` для АУСН «доходы». Для АУСН «доходы минус расходы» поставьте `usn_income_outcome`. Отдельного признака АУСН в чеке нет, налоговая определяет режим по ИНН.

`PUBLIC_BASE_URL` можно оставить пустым. Бот тогда сам спрашивает статус платежа у банка. Постоянный https-адрес нужен, когда бот переедет на свой сервер и должен получать уведомления мгновенно.

Сертификат Т-Банка выпущен удостоверяющим центром Минцифры. Этот корневой сертификат лежит в `certs/` и добавляется к проверке соединения: на многих серверах его нет в системном хранилище.

На тестовом терминале с суффиксом DEMO бот не передаёт сохранение карты. Иначе кабинет Т-Банка не засчитывает тест «Успешная оплата», хотя сама оплата проходит. На боевом терминале карта сохраняется. `TBANK_RECURRENT=1` включает сохранение и на тестовом.

## Команды владельца

Меню этих команд видно только id из `ADMIN_IDS`. Вход: `/admin`.

- `/price` — цены. `/price 12 37990` меняет обычную цену. `/price 12 28490 10.11.2026` включает акцию до конца дня. `/price 12 clear` убирает акцию.
- `/promo` — список. `/promo NEWYEAR 20% 12` создаёт одноразовый код. `/promo off NEWYEAR` выключает его.
- `/grant 123456789 12` — доступ без оплаты.
- `/who 123456789` — карточка человека.
- `/stats` — число доступов и сумма реестра.
- `/export` — CSV.
- `/refund id` — возврат, когда подключён терминал Т-Банка.

Канал запоминается сам, когда владелец назначает бота администратором. Пересылка поста из канала тоже подходит.
